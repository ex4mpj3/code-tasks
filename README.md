# Задание №7. Вариант 12. Стек и скобки

## Задание

Это задание повышенной сложности: за его выполнение можно получить дополнительные баллы.

Для выполнения задания используйте классы `ListNode` и `LinkedList` из решения задания 3, вариант 12. Эти классы и соответствующие тесты не изменять: структуру данных стек реализовать только средствами готового списка.

В файле `stack.py` реализовать класс `Stack`:

- `push` — положить элемент на вершину;
- `pop` — снять и вернуть вершину;
- `peek` — вернуть вершину, не снимая её;
- `is_empty` — проверить, пуст ли стек;
- `__len__` — число элементов.

В файле `main.py` реализовать функцию `is_brackets_balanced` с использованием структуры данных стэк. Функция проверяет согласованность открывающих и закрывающих скобок разных типов в математическом выражении. Учитываются скобки `()`, `[]` и `{}`. Остальные символы пропускаются. Пустая строка и строка без скобок согласованы. Каждой открывающей скобке должна соответствовать закрывающая того же вида, причём закрывается последняя ещё не закрытая скобка. Аргумент, не являющийся строкой, даёт `TypeError`.

В файле `class-diagram.md` приведите диаграмму классов решения. Это блок Mermaid `classDiagram` в Markdown, как в задании 3. Диаграмма должна совпадать с решением. 

В файлах `test_stack.py` и `test_brackets.py` приведены примеры. Команда расширяет набор тестов, чтобы убедиться в корректности своего решения. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

2. Корректность реализации проверить запуском модульных тестов в файлах `test_stack.py` и `test_brackets.py`.
3. После установки зависимостей проекта:
   - проверка синтаксиса и оформления: `ruff check .`
   - форматирование: `ruff format .`
4. Результат выполнения задания — Pull request: в **base** — ветку с заданием, из **compare** — ветки команды с решением. Не направлять запрос в `main`.
5. Программный код пишут и правят только участники команды. **Генеративные модели и средства автодополнения кода** использовать для написания и редактирования программного кода нельзя. На защите нужно объяснить код и идеи, заложенные в его реализацию, а также ответить на вопросы по теме задания и материалам лекции.

## По теме

**Стек** хранит элементы по правилу LIFO: последним пришёл — первым ушёл. Операции `push` и `pop` относятся к одному и тому же концу, вершине стека. Просмотр вершины её не удаляет.
