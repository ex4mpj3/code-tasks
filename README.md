## По теме

**Динамическое программирование** опирается на принцип оптимальности Беллмана: оптимальное решение строится из оптимальных решений подзадач.

Путешественник идёт по таблице $a_{ij}$ из клетки $(0,0)$ в клетку $(n-1,m-1)$. Из $(i,j)$ можно перейти только в $(i,j+1)$ или в $(i+1,j)$. Стоимость пути — сумма цен всех посещённых клеток.

Обозначим $F(i,j)$ минимальную стоимость пути из $(0,0)$ в $(i,j)$. Тогда
$F(0,0)=a_{00}$,
$F(0,j)=F(0,j-1)+a_{0j}$,
$F(i,0)=F(i-1,0)+a_{i0}$,
а во внутренних клетках

$$
F(i,j)=a_{ij}+\min(F(i-1,j), F(i,j-1)).
$$

Ответ задачи — $F(n-1,m-1)$ и один путь, на котором эта стоимость достигается. Если таких путей несколько, в этом задании подходит любой.
