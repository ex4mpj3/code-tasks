# Задание №6. Вариант 5. Размен монет

## Задание

В файле `main.py` реализовать функцию:

- `coin_change` — по списку номиналов и сумме вернуть именованный кортеж `Result` с полями `count` (минимальное число монет) и `combination` (список номиналов, сумма которых равна заданной). Если сумму набрать нельзя, вернуть `Result(None, None)`.

Каждый номинал можно брать сколько угодно раз. Порядок монет в `combination` не фиксируется. Если минимальных наборов несколько, достаточно вернуть любой из них. Для суммы $0$ ответ — `Result(0, [])`.

В `main.py` уже объявлен `ErrorMessages` (`StrEnum` со стандартной библиотеки). Тексты ошибок брать из перечисления, не копировать строками.

**В этом задании** `coins` — непустой список целых положительных номиналов; `bool` целым не считается. `amount` — целое неотрицательное. Если `coins` не список — `TypeError` с `ErrorMessages.COINS_NOT_LIST`. Если `amount` не целое — `TypeError` с `ErrorMessages.AMOUNT_NOT_INT`. Если номинал не целое — `TypeError` с `ErrorMessages.COIN_NOT_INT`. Пустой список — `ValueError` с `ErrorMessages.WRONG_COINS`. Отрицательная сумма — `ValueError` с `ErrorMessages.WRONG_AMOUNT`. Номинал не больше нуля — `ValueError` с `ErrorMessages.NEGATIVE_COIN`.

Пример использования — в `main.py`.

В файле `test.py` приведены примеры. Команда расширяет набор тестов, чтобы убедиться в корректности своего решения. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

## По теме

**Динамическое программирование** опирается на принцип оптимальности Беллмана: оптимальное решение строится из оптимальных решений подзадач.

Даны номиналы $c_1,\ldots,c_n$ и сумма $S$. Нужно набрать $S$, используя каждое $c_i$ любое число раз, так чтобы число монет было минимальным.

$F(s)$ — минимальное число монет для суммы $s$. Тогда $F(0)=0$, а при $s>0$

$$
F(s)=\min_{c_i\le s}\bigl(F(s-c_i)+1\bigr),
$$

если ни одна монета не подходит или все такие $F(s-c_i)$ не определены, суммы $s$ набрать нельзя. Ответ задачи — $F(S)$ и один набор монет, на котором это число достигается. Если таких наборов несколько, в этом задании подходит любой.
