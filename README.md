## По теме

**Динамическое программирование** опирается на принцип оптимальности Беллмана: оптимальное решение строится из оптимальных решений подзадач.

Путешественник идёт по таблице из клетки $(0,0)$ в клетку $(n-1,m-1)$. Из $(i,j)$ можно перейти только в $(i,j+1)$ или в $(i+1,j)$. Стоимость пути — сумма цен всех посещённых клеток. Клетка $a_{ij}=\mathrm{None}$ непроходима: через неё путь не проходит.

Обозначим $F(i,j)$ минимальную стоимость пути из $(0,0)$ в $(i,j)$. Если клетка запрещена или в неё нельзя попасть, пути нет. Иначе
$F(0,0)=a_{00}$, а во внутренних достижимых клетках

$$
F(i,j)=a_{ij}+\min(F(i-1,j), F(i,j-1)),
$$

где в минимум входят только достижимые соседи сверху и слева.

Если финиш недостижим — в том числе когда запрещены старт или финиш — функция возвращает `Result(None, None)`. Если оптимальных путей несколько, в этом задании подходит любой.
