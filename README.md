# Задание №6. Вариант 6. Рюкзак динамическим программированием

## Задание

В файле `knapsack_abs_solver.py` реализовать методы класса `KnapsackAbstractSolver`:

- `get_weight` — суммарный вес выбранных предметов;
- `get_cost` — суммарная стоимость выбранных предметов; если набор тяжелее вместимости, вернуть $0$;
- `_validate_params` — проверка входа (вместе с `_validate_list`).

В файле `dynamic_solver.py` реализовать метод `get_knapsack` класса `DynamicSolver`: набор максимальной стоимости, не тяжелее вместимости, динамическим программированием. Для веса и стоимости набора использовать методы родительского класса. Результат — `KnapsackSolution` с полями `cost` и `items` (индексы выбранных предметов, с нуля). Порядок индексов в этом задании не фиксируется. Если оптимальных наборов несколько, достаточно вернуть любой из них.

Каждый предмет берут не больше одного раза.

Пример использования — в `main.py`.

**В этом задании** веса и стоимости — непустые списки целых чисел, строго больших нуля, одной длины; `bool` целым не считается. Вместимость — целое число, не меньше $1$ и не меньше минимального веса предмета. Иначе:

- веса или стоимости не список — `TypeError`, «Веса не являются списком» / «Стоимости не являются списком»;
- пустой список — `ValueError`, «Веса являются пустым списком» / «Стоимости являются пустым списком»;
- нецелое в списке — `TypeError`, «Веса содержат нецелое значение» / «Стоимости содержат нецелое значение»;
- нуль или отрицательное в списке — `ValueError`, «Веса содержат нулевое или отрицательное значение» / «Стоимости содержат нулевое или отрицательное значение»;
- разная длина списков — `ValueError`, «Списки весов и стоимости разной длины»;
- вместимость не целое — `TypeError`, «Ограничение вместимости рюкзака не является целым числом»;
- вместимость меньше единицы — `ValueError`, «Ограничение вместимости рюкзака меньше единицы»;
- вместимость меньше минимального веса — `ValueError`, «Ограничение вместимости рюкзака меньше чем минимальный вес предмета».

В файле `test.py` приведены примеры. Команда расширяет набор тестов, чтобы убедиться в корректности своего решения. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

## По теме

**Динамическое программирование** опирается на принцип оптимальности Беллмана: оптимальное решение строится из оптимальных решений подзадач.

**Задача о рюкзаке** (0-1): даны $N$ предметов, у $i$-го вес $w_i>0$ и стоимость $p_i>0$. Нужно выбрать подмножество, чтобы суммарный вес не превосходил вместимости $W$, а суммарная стоимость была максимальна. Каждый предмет берут не больше одного раза.

Задача NP-полная: неизвестен алгоритм с полиномиальной гарантией в общем случае. Полный перебор даёт $2^N$ наборов. Динамическое программирование строит ответ по подзадачам «первые $i$ предметов, вместимость $w$».

$F(i,w)$ — максимальная стоимость при первых $i$ предметах и вместимости $w$. Тогда $F(0,w)=0$, $F(i,0)=0$. Если $w_i>w$, то $F(i,w)=F(i-1,w)$, иначе

$$
F(i,w)=\max\bigl(F(i-1,w),\, F(i-1,w-w_i)+p_i\bigr).
$$

Ответ задачи — $F(N,W)$ и индексы предметов одного такого набора. Если оптимальных наборов несколько, в этом задании подходит любой.
