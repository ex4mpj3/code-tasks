# Задание №7. Вариант 11. Генерация перестановок

## Задание

Это задание повышенной сложности: за его выполнение можно получить дополнительные баллы.

В файле `main.py` реализовать две функции:

- `generate_permutations_rec` — все перестановки заданного списка элементов рекурсивно;
- `generate_permutations_iter` — те же перестановки итеративно, без рекурсии.

Порядок перестановок в возвращаемом списке не фиксируется. Повторы и пропуски недопустимы.

**В этом задании** аргумент — список. Элементы могут быть любыми объектами. Если аргумент не список, в том числе `bool`, строка и кортеж, функция даёт `TypeError`. Пустой список даёт список из одной пустой перестановки.

В файле `test.py` приведены примеры. Команда расширяет набор тестов, в том числе с учетом ограничений предметной области, чтобы убедиться в корректности своего решения. При проверке учитываются и тесты команды, и дополнительные проверки преподавателя, которые в репозиторий не публикуются.

## По теме

Перестановка $n$ элементов — упорядоченный набор, в котором каждый из них встречается один раз. Таких перестановок $n!$. При $n = 0$ есть одна пустая перестановка: $0! = 1$. Элементы не обязаны быть числами.
